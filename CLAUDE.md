# herrera-piezas (público)

Solo piezas **aprobadas por el dueño**, listas para Metricool. Las reglas, el contexto y los borradores viven en el repo privado `herrera-contenido` (su `CLAUDE.md` manda).
- Nunca subir aquí notas, precios internos, borradores ni datos de clientes.
- Una carpeta por semana (`semana-NN/`), nombres en minúsculas con guiones, máx. 100 MB.
- Primero commit y push a `main`, después `python enlace_publico.py <archivo>` para el enlace.
- No hacer commit ni push sin que el dueño lo pida.
