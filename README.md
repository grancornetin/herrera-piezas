# Herrera Producciones · piezas aprobadas

Aquí solo van las piezas de contenido **ya aprobadas por el dueño** (reels, portadas, láminas de carrusel), listas para programar en Metricool.

Este repositorio es **público**: cualquier persona puede ver lo que se sube. Por eso aquí **no** van borradores, notas, precios internos ni datos de clientes. Todo eso vive en el repositorio privado del cerebro de contenido.

## Cómo se ordena
- Una carpeta por semana: `semana-02/`, `semana-03/`…
- Nombres en minúsculas con guiones, sin espacios ni tildes. Ejemplo: `semana-02/reel-fotocabina.mp4`, `semana-02/reel-fotocabina-portada.jpg`.
- Máximo 100 MB por archivo.

## Enlace para Metricool
Cada archivo subido tiene un enlace directo:
`https://raw.githubusercontent.com/grancornetin/herrera-piezas/main/<ruta del archivo>`

Para sacarlo sin errores: `python enlace_publico.py semana-02/reel-fotocabina.mp4` (o `--carpeta semana-02`).
